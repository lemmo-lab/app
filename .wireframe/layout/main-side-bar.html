Lemmo Workspace — Sidebar Wireframe Standard

This interactive wireframe models the 2-state navigation rail of Lemmo Studio according to the Lemmo Design System standards (DOC-DS-001 & DOC-DS-005).

  • Standardized 4px Ladder Grid Expanded: 256px (was 255px). Collapsed: 72px mini-rail (56px content + 16px padding).
  • Fixed Avatar Dimensions 40px circular shape with dedicated container. Perfectly centered in 56px collapsed slot.
  • Prominent Brand Mark 32px brand logo in expanded header, transitioning into a 44px centered toggle button in collapsed mode.
  • Logical CSS & Directionality Default is LTR as specified. Full logical property support (margin-inline, border-inline) for instant RTL flipping.
  • Button Touch Targets Items snapped to 40px height with 8px radius, conforming to design system primitives.
  • Active State Indication Accent lime bar marker on active tab with subtle border elevation.
